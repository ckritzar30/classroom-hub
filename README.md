# Classroom Hub

A Schoology-inspired classroom dashboard prototype built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Upload through GitHub.com

1. Create a public repository named `classroom-hub`.
2. Extract this ZIP file.
3. In the repository, select **Add file** and then **Upload files**.
4. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and this `README.md`.
5. Commit the files to the `main` branch.
6. Open **Settings > Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select `main` and `/ (root)`, then save.

The expected address is:

`https://ckritzar30.github.io/classroom-hub/`

## Important

This is a static demonstration. Do not put real student records, passwords, grades, private messages, or secret API keys in this repository.
